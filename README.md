# Amazon Prime Video Clone 🎬

A responsive front-end clone of **Amazon Prime Video**, built using **HTML, CSS, and JavaScript**.  
This project focuses on recreating the UI/UX, responsiveness, and interactive components of the Prime Video web interface.

---

## 🔥 Features

- Fully responsive design (Desktop, Tablet, Mobile)
- Sticky navigation bar
- Interactive **Categories dropdown**
- Language selection popup
- User account menu popup
- Expanding search bar
- Responsive channel grid (3 per row on desktop)
- Smooth scrolling navigation
- Clean, modern Prime Video–style UI

---

## 📱 Responsive Behavior

| Device | Layout |
|------|------|
| Desktop / Laptop | 3-channel grid, full navigation |
| Tablet | 2-channel grid, wrapped navigation |
| Mobile | 1-channel grid, stacked layout |

The layout is optimized for **100% browser zoom** (no zoom hacks required).

---
